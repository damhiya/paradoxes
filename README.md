# Paradoxes
Formalization of type theoretic paradoxes.

## Coquand92
Reproduction of Russell and Burali-Forti's paradoxes using a universe containing itself and inductive type.

## Coquand24
Reproduction of Russell's paradox using a universe containing itself.

## Curry
Curry's paradox.

## Hurkens
Hurkens' paradox using a universe containing itself.

## CoinductiveTree
Coinductive version of Coquand92.
